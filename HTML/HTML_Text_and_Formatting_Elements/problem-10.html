About the University

GLA University is a private university located in Mathura, Uttar Pradesh, India, and Greater Noida offering undergraduate, postgraduate, and doctoral programs across multiple disciplines.

The university focuses on academic excellence, practical learning, innovation, and overall student development. It provides students with opportunities to participate in technical events, workshops, internships, cultural activities, and sports.

The university aims to prepare students for professional careers while encouraging creativity and lifelong learning.

"A place where knowledge meets innovation and opportunity."

HTML ELEMENTS AND THEIR USES

     

HTML Elements and Their Uses

HTML          Use
Element	  
          
br	     Inserts a line break.
hr	     Creates a horizontal line to separate content.
p	     Defines a paragraph.
h1 to h6     Defines headings from largest (h1) to smallest (h6).
mark	     Highlights text.
u	     Underlines text.
i	     Displays text in italic style.
em	     Emphasizes text, usually displayed in italics.
strong       Shows strong importance, usually displayed in bold.
b	     Makes text bold without adding semantic importance.
pre	     Displays preformatted text, preserving spaces and line breaks.
code         Displays a piece of computer code.
sup	     Displays text as a superscript, e.g. x2.
sub	     Displays text as a subscript, e.g. H2O.
