Important Terms

RAM
Temporary memory used by the laptop.
SSD
Fast storage for files and programs.
CPU
The main processor of the computer.
GPU
Handles graphics and visual tasks.
Refresh Rate
Number of screen refreshes per second.
Battery Capacity
Amount of energy stored in the battery.
